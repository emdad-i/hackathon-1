# Developer Setup

Welcome to the hackathon. Do these four things before you start coding. It should take about 15 minutes.

| # | Setup | Time | Guide |
| --- | --- | --- | --- |
| 1 | Install VS Code | 5 min | [vscode.md](vscode.md) |
| 2 | Create a GitHub account and get repo access | 5 min | [github.md](github.md) |
| 3 | Join the Discord server | 2 min | [discord.md](discord.md) |
| 4 | Install the OpenCode CLI (no key needed) | 5 min | [opencode.md](opencode.md) |

## Standard setup

Our standard setup is **VS Code + GitHub + Discord + OpenCode**. If you already have a preferred editor (Cursor, Zed, JetBrains, Vim), feel free to use it — just make sure it can run your project and format your code. Everything else is required.

## How we work

- **GitHub** (`hackathon-1` repo) — all code, commits, CI, and project tickets.
- **Discord** — all communication, quick calls, and team coordination.
- **OpenCode** — AI pair programmer, running **DeepSeek V4.1 Flash (free)**. No account or key is needed; the repo's `.opencode/opencode.jsonc` is already configured. See [opencode.md](opencode.md). Backup credits for the same model are on Hugging Face.

## First-day checklist

- [ ] VS Code opens this repo
- [ ] `git clone` works and you can push a branch
- [ ] You can post in Discord and join a voice channel
- [ ] `opencode` starts on DeepSeek V4.1 Flash Free

Stuck? Ask in the Discord `#help` channel. Include the command you ran and the full error.
