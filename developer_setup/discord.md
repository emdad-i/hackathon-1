# 3. Discord

Discord is our main communication channel for the whole event.

We use it for:

- **Chat** — `#general` for questions, progress, and finding teammates
- **Help** — the `#help` channel for blockers
- **Calls** — `#conference`, a live video call of the room

## Install

### macOS

Download from <https://discord.com/download> and drag it into Applications, or:

```bash
brew install --cask discord
```

### Windows

```powershell
winget install --id Discord.Discord -e
```

Or download from <https://discord.com/download>.

The browser version at <https://discord.com/app> works too, but the desktop app handles calls and notifications better.

## Create an account

1. Go to <https://discord.com/register>
2. Use the same email you used for GitHub if possible
3. Verify your email

1. Open the invite link shared by the organisers: `DISCORD_INVITE_LINK`
2. Accept the invite and complete any onboarding prompts
3. Set your server nickname to your **real name** so people can find you

## Join the room from anywhere

`#conference` is a video call pointed at the hackathon room. Join it to talk to your teammates while you work, whether you are in the room or remote:

- The call shows the room, so you can see what is going on and who is around.
- If you join remotely, you are **videoed into a TV in the room**, so your teammates can see and hear you.
- You can speak to the whole room from the call — use it for quick questions instead of typing.

There are only three channels: `#general`, `#help`, and `#conference`.

## How to use it well

- **Use the right channel.** `#help` for blockers, `#general` for chat, `#conference` for talking to the room.
- **Thread replies** for long debugging conversations.
- **Join `#conference`** when you want to pair or ask something out loud — the mic is always available there.
- **@mention** the person you need, not `@everyone`.
- **Mute the server** and enable notifications only for mentions if it gets noisy.
- **Keep secrets out of chat.** Never paste API keys, tokens, or passwords.
